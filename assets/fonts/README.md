# Self-hosted IBM Plex fonts

The syllabus uses IBM Plex Sans for text and IBM Plex Mono for labels and code.
The WOFF2 files were retrieved from Google Fonts on August 25, 2026, and copied
from the CPEN 221 readings site. Latin and Latin Extended subsets are included.
Both families are distributed under the SIL Open Font License 1.1; verbatim
licence files are in `licenses/`.
